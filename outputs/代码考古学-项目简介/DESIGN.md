# DESIGN.md · 代码考古学 项目简介

> 风格路由结论：**通用设计原则（universal-only）**。
> 本主题不落入学术答辩 / 商务咨询 / 红金政务三条垂直分支，故不生成领域特化稿，
> 由 AI 依据主题（开发者工具 · 考古学隐喻）原创设计。

## 1. 设计概念：「地层剖面」

考古学家的现场是**地层**——一层压一层，越往下越久远；文物藏在人类活动的层里，
被机器人沉积物（依赖升级、锁文件）掩埋。整个 deck 的视觉语言统一为：
**深燧石底色（土壤）· 青铜绿（人类信号）· 琥珀金（文物 / 关键数字）**。

- 抽象几何、结构化的主视觉（地层剖面、流水线）**用 SVG 手绘**，不使用 AI 生图。
  理由：本 deck 的主视觉全部是结构化 / 低语义元素（地层剖面、三段流水线、数据条），
  通用设计原则 §5.3 明确允许；用摄影图反而削弱开发者工具的工程可信度。

## 2. 画布与母版（默认 A/B/C 三区）

| 母版区 | 垂直位置 | 高度 | 规则 |
| :--- | :--- | :--- | :--- |
| A · 标题块 | 0–120px | 120px（含上 padding 20） | 主标题 34px bold；右上角为**双语页码锚点**，全篇位置一致 |
| B · 内容区 | 120–660px | 540px 可用 | 全部正文、图示、卡片 |
| C · 页脚条 | 660–720px | 60px（含下 padding 20） | 左侧 `代码考古学 / Code Archaeology` + 右侧 `NN / 05`，统一 14px |
| 页面 padding | 20px 上下 · 60px 左右 | — | A/B/C 在此范围内排布 |

- 封面（01）采用全幅自定义版式，省略 C 区，页码锚点保留在右下角。
- 02–05 严格复用 A/B/C 骨架，标题基线与页码位置逐页一致。

## 3. 色彩池（4 个 hex + 2 级中性墨）

| 角色 | HEX | 面积占比 | 用途 |
| :--- | :--- | :--- | :--- |
| 主色 · 深燧石 | `#10141A` | ≤ 60% | 页面底色、全幅背景 |
| 辅色 · 陶土灰 | `#1D242E` | ≤ 30% | 卡片背景、分隔条、次级面板 |
| 强调色 · 琥珀金 | `#E3A33E` | ≤ 10%（hero 页可到 18%） | 巨型数字、关键 SHA、文物高亮层 |
| 信号色 · 青铜绿 | `#4CB8A6` | ≤ 8% | 人类决策 / 已核实为真 / 正向数据 |
| 中性墨（非彩色） | `#EDF1F5` / `#8892A0` | 剩余 | 正文与脚注 |

**页面色彩映射**

| 页 | 主色 | 辅色 | 强调色 | 色彩节奏 |
| :--- | :--- | :--- | :--- | :--- |
| 01 封面 | 62% | 18% | 14% | hero：琥珀大爆发（地层高亮层 + 巨字） |
| 02 问题 | 58% | 30% | 4% | supporting：几乎无强调色，刻意压抑 |
| 03 方案 | 55% | 28% | 10% | 琥珀（流水线）与青铜绿（信号）对分 |
| 04 实证 | 52% | 22% | 18% | hero：巨型数字，琥珀 + 青铜绿双锚点 |
| 05 价值 | 60% | 30% | 6% | supporting：回归克制，末尾金句条用琥珀收束 |

**渐变与半透明**

- 封面底层：`linear-gradient(160deg, #10141A 0%, #18202A 100%)`
- 卡片浮起：`boxShadow: '0 6px 24px rgba(0,0,0,0.35)'`
- 装饰层：`rgba(227,163,62,0.08)` / `rgba(76,184,166,0.10)`，叠于主色之上
